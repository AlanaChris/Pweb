APIs e Integrações


APIs, ou Interfaces de Programação de Aplicativos, são um conjunto de regras ou protocolos os quais permitem que aplicações de software se comuniquem

A seguir, vamos abordar alguns tipos de API e Integrações:



APIs remotas ou APIs Web

APIs remotas, ou web, utilizam recursos localizados fora do computador que realiza a solicitação.

Elas permitem a integração de sistemas de terceiros, bancos de dados e serviços de nuvem, sendo comuns em REST e SOAP.

API SOAP e API REST

APIs SOAP emergiram a partir da proliferação das APIs web, elas utilizam XML como formato de mensagem e recebem solicitações por HTTP ou SMTP.

APIs REST são um estilo de arquitetura do tipo cliente-servidor recebendo solicitações em HTTP, possui código sob demanda e um sistema em camadas.

GraphQL

A GraphQL apresenta uma alternativa a API REST, fornecendo somente os dados solicitados pelo cliente, além de permitir que os desenvolvedores construam solicitações capazes de extrair dados de diversas fontes a partir de uma única chamada de API.







Integração com API

  • Integrações de software empresarial

    • As organizações dependem da integração com API para simplificar e automatizar seus fluxos de trabalho em sistemas de software corporativos.


  • Integrações de serviços de nuvem

    • As organizações usam APIs para integrar vários ambientes de computação em nuvem e no local.


  • Integração do sistema de mensagens

    • Os usuários encontram esses tipos de integrações (muitas vezes sem saber) em ambientes comerciais e não comerciais. Aplicações como o Slack usam APIs para integrar à plataforma outros softwares de negócios que os funcionários usam para colaborar.
